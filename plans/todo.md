3. Query Expansion (查询扩展)

- 改写用户查询
- 生成多个相似查询并行检索
- 适合用户表述不清晰的场景

1. 细节问题（最高频）
   "XX是什么？"、"XX怎么用？" ——用混合检索（向量+关键字）基本能搞定。
2. 全局问题
   "文档讲了什么？"、"核心观点是什么？" ——预计算摘要索引解决。
3. 比较问题
   "A和B的区别？"、"哪个更好？" ——用户问文档内容时非常常见，多路并行检索后聚合。
4. 多跳问题
   "负责XX的人用什么工具？" ——知识库稍复杂时就会出现，迭代检索解决。

先用混合搜索召回前 10-20 个片段，然后再通过一个重排序模型（Reranker）。Reranker 会像人类精读一样，重新审视这 20 个片段里哪个才是真正包含那个“细节”的，这能极大提升最终答案的准确率。

全局问题 → 摘要索引 / 全文摘要
将文档切块后，先对每个小块生成摘要，再对摘要群生成更高一级的摘要，直到最后生成整份文档的总括。
全局性问题：
有标题的文档 → 生成思维导图，总结
不搜索、不过滤，直接获取文档的目录结构

局部问题 → 向量检索 / 关键字检索
比较问题 → 多路检索后聚合

# 全局模式检索

## 概述

全局模式是一种基于文档目录结构的问答方式，适用于了解文档整体框架和章节安排的问题。

与局部模式（基于具体内容检索）不同，全局模式直接使用文档的目录结构作为上下文，让 LLM 基于整体框架回答问题。

---

## 适用场景

| 模式 | 适用问题类型 | 示例问题 |
|------|-------------|---------|
| **全局模式** | 文档整体框架、章节安排、概览类问题 | "这本书的主要内容是什么？"、"有哪些章节？"、"文档结构是怎样的？" |
| **局部模式** | 具体细节、事实查询、内容理解 | "什么是 XXX？"、"如何使用 YYY 功能？"、"ZZZ 的原理是什么？" |

---

## 支持的文档类型

全局模式仅支持**结构性文档**（具有明确标题层级）：

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| Markdown | `.md`, `.markdown` | 使用 `#`、`##` 等标题标记 |
| EPUB | `.epub` | 具有 NCX 目录结构 |

**注意**：PDF、Word 等格式不支持全局模式。

---

## 工作流程

```
用户选择全局模式
    │
    ▼
获取文档目录结构 (get_toc)
    │
    ├─ Markdown: 提取 h1-h6 标题层级
    └─ EPUB: 提取章节目录
    │
    ▼
构建提示词 (GLOBAL_SYSTEM_PROMPT)
    │
    ├─ 目录结构作为上下文
    └─ 用户问题
    │
    ▼
LLM 生成回答
    │
    ▼
展示结果 + 目录结构
```

## 代码实现

### 核心文件

| 文件 | 说明 |
|------|------|
| `src/chains/qa_chain.py` | `run_global()` 方法、`GLOBAL_SYSTEM_PROMPT` 提示词 |
| `src/web/components/chat.py` | `_get_global_context()` 函数、全局模式路由 |
| `src/loaders/markdown_loader.py` | `get_toc()` 提取 Markdown 目录 |
| `src/loaders/epub_loader.py` | `get_toc()` 提取 EPUB 目录 |
| `src/config.py` | `STRUCTURED_DOC_TYPES` 配置 |

### 全局模式提示词

```python
GLOBAL_SYSTEM_PROMPT = """你是一个专业的知识库助手。请根据以下文档的目录结构回答用户的问题。

要求：
1. 只根据提供的目录结构回答问题
2. 目录结构展示了文档的整体框架和章节安排
3. 回答要准确、简洁、有条理
4. 对于具体细节，建议用户切换到局部模式

文档目录结构：
{toc}

用户问题：
{question}

请回答："""
```

### 数据流

```python
# 1. 用户选择全局模式
st.session_state.search_scope = "global"

# 2. 获取目录结构
toc_context, has_support = _get_global_context(vector_store)

# 3. 调用全局问答
result = qa_chain.run_global(query, toc_context)

# 4. 返回结果（包含目录结构）
return {
    "answer": result.answer,
    "citations": [],
    "toc_context": toc_context  # 用于 UI 展示
}
```

## 示例

### 上传文档

```
docs/python_tutorial.md (Markdown 格式)
├── # 第一章 Python 简介
│   ## 1.1 Python 历史
│   ## 1.2 安装 Python
├── # 第二章 基础语法
│   ## 2.1 变量与数据类型
│   ## 2.2 控制流程
```

### 全局模式问答

**问题**："这个文档的主要内容是什么？"

**回答**：
> 这份文档介绍了 Python 编程的基础知识。主要包含两章：第一章介绍 Python 的历史和安装方法，第二章讲解基础语法，包括变量、数据类型和控制流程等内容。

**目录结构**：
```
- 第一章 Python 简介
  - 1.1 Python 历史
  - 1.2 安装 Python
- 第二章 基础语法
  - 2.1 变量与数据类型
  - 2.2 控制流程
```

---

## 注意事项

1. **目录顺序**：目录结构按照文档中的原始顺序显示，不进行字母排序
2. **无引用**：全局模式不显示具体文档引用，只显示目录结构
3. **文档限制**：只有 Markdown 和 EPUB 格式支持全局模式
4. **细节问题**：对于具体细节问题，建议切换到局部模式

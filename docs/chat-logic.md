## 完整流程

```
局部模式：用户输入 → 验证 → 检索 → Reranker重排序 → LLM生成 → 引用生成 → 后续问题 → 展示结果

全局模式：用户输入 → 验证 → 获取目录结构 → LLM生成 → 展示结果 + 目录结构
```

## 详细步骤

### 局部模式

| 步骤 | 位置 | 说明 |
|------|------|------|
| 1. 捕获输入 | `chat.py` | `st.chat_input()` |
| 2. 验证 | `chat.py` | API Key + 文档存在性 |
| 3. 选择检索器 | `chat.py` | 语义/全文/混合检索 |
| 4. 检索 | `qa_chain.py` | `retriever.get_sources()` |
| 5. Reranker | `qa_chain.py` | FlashRank 重排序 |
| 6. 构建上下文 | `qa_chain.py` | 含标题层级的格式化 |
| 7. LLM 生成 | `qa_chain.py` | OpenRouter API |
| 8. 生成引用 | `qa_chain.py` | 书名/章节/页码/分数 |
| 9. 后续问题 | `chat.py` | 生成 3 个递进问题 |
| 10. 展示 | `chat.py` | 答案 + 可展开引用 |

### 全局模式

| 步骤 | 位置 | 说明 |
|------|------|------|
| 1. 捕获输入 | `chat.py` | `st.chat_input()` |
| 2. 验证 | `chat.py` | API Key + 文档存在性 + 文档类型检查 |
| 3. 获取目录结构 | `chat.py` | `_get_global_context()` 调用 loader 的 `get_toc()` |
| 4. LLM 生成 | `qa_chain.py` | `run_global()` 基于目录结构 |
| 5. 展示 | `chat.py` | 答案 + 可展开目录结构 |

## 检索模式

### 局部模式检索

| 模式 | 方式 | 场景 |
|------|------|------|
| 语义检索 | 向量相似度 | 理解语义 |
| 全文检索 | BM25 关键词 | 精确匹配 |
| 混合检索 | Ensemble (可调权重) | 最佳效果 |

### 全局模式检索

| 模式 | 方式 | 场景 | 支持格式 |
|------|------|------|---------|
| 全局模式 | 目录结构 | 文档整体框架、章节安排 | Markdown, EPUB |

## 引用格式

```
《书名》-章节 (第X页) [85%]
```
